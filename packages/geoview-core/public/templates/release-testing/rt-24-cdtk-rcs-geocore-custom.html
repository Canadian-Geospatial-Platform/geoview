24 — CDTK, RCS & Geocore Custom Tests

CDTK (Cloud Data Toolkit / QGIS) WMS and WFS services, RCS (Remote Config Service), and Geocore with inline/VCS custom overrides.

Test plan: 24-cdtk-rcs-geocore-custom.md

Map 1 — CDTK WMS Basic

QGIS WMS layers from qgis-stage.cdtk.geogc.ca. Tests basic load, fetchVectorsOnWFS: false, raster tile rendering.

Map 2 — CDTK WMS with Geocore

Mixed source config: geocore and CDTK layers together. Tests custom featureInfo config (nameField, outfields).

Map 3 — CDTK WFS Basic

QGIS WFS layers with fetchStylesOnWMS: false, custom inline uniqueValue style, multiple sublayer entries per layer.

Map 4 — CDTK WFS with featureInfo

CDTK WFS layers with nameField and outfields config applied. Tests feature query and details display.

Map 5 — RCS (Remote Config Service)

RCS geocore variant for VPN environments. Tests UUID resolution, legend, and feature query.

Map 6 — Geocore with Custom Inline Config

Geocore UUID with custom listOfLayerEntryConfig, custom groups, initial visibility states, style overrides, and geoviewLayerName override.

Map 7 — Geocore with VCS Custom Config

Geocore UUIDs with VCS-published customizations (time slider, geochart configs). Tests VCS override resolution and plugin initialization.

Map 8 — Geocore WMS

Geocore UUID resolving to WMS. Tests WMS legend (GetLegendGraphic) and WMS GetFeatureInfo.
