08 — Layers Panel Tests

Left panel (reorder, visibility, collapse, delete), right panel (info, settings, shortcuts, actions, opacity, style classes). For "Add Layer" tests, use the dedicated Add Layers demo page.

Test plan: 08-layers.md

Map 1 — Layers Panel (Groups, Settings, Style Classes)

GeoCore group layers (Fieldnotes = ESRI dynamic groups, Hydro = WMS groups with scale limits) + simple layer + ESRI Feature layers with uniqueValue/classBreaks style classes. Layers panel in footer bar for reorder, visibility, settings, opacity, shortcuts.

Map 2 — WMS & ESRI Image Layer Settings

WMS layers from wms.json with settings panels. ESRI Image layer for raster function and mosaic rule settings.

Map 3 — Esri Dynamic: Group of Groups

Multi-level group hierarchy (groups within groups). Tests expand/collapse, visibility per level, feature query on nested leaves.

Map 4 — Esri Dynamic: Projections (forceServiceProjection)

Tests forceServiceProjection flag: OL reproject-on-the-fly vs server-side reprojection. Switch projection and verify no artifacts.

Map 5 — Vector Tiles

CBCT French and CBMT English vector tile layers with styleUrl. Toggle independently, zoom for level-of-detail.

Map 6 — WKB (Well-Known Binary)

Two WKB layers (South Africa polygons): one from metadataAccessPath hex string, one from dataAccessPath. Initial view zooms to layerIds.

Map 7 — Shapefile (ZIP)

Local shapefiles in ZIP (Crown Harvest Plans, Sunchild Aquifer), remote shapefile (Wildfire HotSpots .shp with uniqueValue style on SOURCE field).

Map 8 — GeoJSON Multi

Multiple GeoJSON layers with mixed geometry types (points, lines, polygons). Independent visibility toggle.

Map 9 — All Layer Zoom Levels (Comprehensive)

Zoom and scale constraints across ALL layer types simultaneously. Zoom in/out to verify layers appear/disappear at configured thresholds.
