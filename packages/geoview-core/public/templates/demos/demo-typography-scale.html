GeoView typography scale

The samples use the map's GeoView theme and show the computed browser size for every typography variant. The design sizes are calibrated to the browser's default font size, rather than the host page's root size.

Choose a host root size below to compare 10px, 16px, and 20px roots. Each choice reloads the page so GeoView measures the root before creating its theme. The browser default remains controlled by your browser's font settings.
