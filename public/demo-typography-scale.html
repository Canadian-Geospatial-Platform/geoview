GeoView typography scale

The samples use the map's GeoView theme and show the computed browser size for every typography variant. The design sizes are calibrated to the browser's default font size, rather than the host page's root size.

Choose a host root size below to compare 10px, 16px, 20px, and 32px roots. Each choice reloads the page so GeoView measures the root before creating its theme. The browser default remains controlled by your browser's font settings.

How to change the default font size in Chrome
  1. Open chrome://settings/fonts in the address bar, or go to Chrome's menu (⋮) → Settings → Appearance → "Customize fonts".
  2. Adjust the "Font size" slider. This value is the browser default ("medium") font size that this demo measures — it is separate from the "Host root size" selector above.
  3. Reload this page afterward; the "Browser default" value in the readout above will reflect the new setting.
